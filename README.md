🔐 Password Manager

A simple Password Manager built using Python and Tkinter as part of the 100 Days of Code challenge.

Features

- Generate random passwords.
- Save website credentials in a text file.
- Search for saved credentials.
- Validate user inputs before saving.

Technologies Used

- Python
- Tkinter
- File Handling

What I Learned

- Building GUI applications using Tkinter.
- Working with files.
- Handling user input and validation.
- Using functions to organize code.

How to Run

1. Clone this repository.
2. Run "main.py".
3. Start managing your passwords!
